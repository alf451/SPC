Test connessione seriale — U-Wave / Digimatic

Strumento diagnostico: apre una porta COM direttamente dal browser e mostra ogni byte ricevuto, per capire cosa manda davvero l'hardware prima di finalizzare il parser dell'Edge Agent. Non fa parte dell'app in produzione.

Questo browser non supporta la Web Serial API. Serve Chrome o Edge (desktop), con la pagina aperta da file://, http://localhost o via HTTPS (non funziona da un indirizzo http://IP-DI-RETE semplice: quello non è un "contesto sicuro"). Firefox e Safari non la supportano affatto.

Connessione disconnesso

Default preimpostato per Mitutoyo U-Wave (57600-N-8-1, come da manuale — vedi external-documents/U-Wave-sintesi-italiano.md). Cambia i parametri per testare altri convertitori Digimatic.

Invia comando (per dispositivi "polled" che richiedono una richiesta esplicita)

U-Wave-T è a comando fisico (tasto sullo strumento): questo campo serve più che altro per convertitori "polled" tipo MicroRidge GageWay (comandi R/B/S/...).
